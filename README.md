# 王子脫魯記 SET｜平權偵察隊（國中版）

這是《一片衛生棉的校園旅行》課程中，供第三節進行的**認知檢核與即時回饋**教材。情境承接前兩節《王子脫魯記》原繪本閱讀及情境變形探究，主要對應性 J3 的性別偏見與歧視、性 J10 的資源運用與分配問題。

> 新版劇本是依教學目標改寫的原創延伸情境，不是《王子脫魯記》原著全文。人物立繪尚未製作，現在顯示「角色圖片待補」。

## 學習流程

1. 閱讀王子的第二趟旅程，認識王子、灰姑娘、長髮公主、賣火柴的小女孩。
2. 依序完成四章十項情境調查：基礎認知2題、性 J3 4題、性 J10 3題、J3×J10整合1題。
3. 每題有3個選項。首次回答、錯誤選擇、回饋重試和最終答對皆保留在學生端紀錄。
4. **B／C：** 完成十題基本認知檢核即達 B；尚未完成為 C。
5. **A：** 通關後填寫一項「性別偏見與可能影響」及一項「資源取得障礙與可能影響」，再由教師判讀是否達 A。程式不按字數或關鍵字自動核定 A。
6. 可下載文字學習紀錄（TXT）或完整資料（JSON），亦可複製摘要。

## 安全氣氛與資料保存

- 不要求分享自身月經經驗，也不要求輸入姓名或班級。
- 無倒數計時與公開排名，答錯後獲得提示並可立即重試。
- 資料存放於該裝置瀏覽器 localStorage；無伺服器、無資料庫、不會自動上傳到教師端。
- 切換裝置、清除瀏覽器資料或無痕模式關閉後，紀錄可能無法恢復，請學生結束時下載檔案。
- 不將遊戲通關描述為已驗證真實生活中的行動能力。

## 專案結構

- index.html：首頁、情境遊戲、結算與進階分析頁。
- assets/style.css：繪本調性介面、手機排版、圖片預留框。
- data/questions.js：十道題目、情境、選項、答案、回饋及概念整理。
- assets/app.js：選項檢核、重試、作答歷程、通關與匿名紀錄匯出。
- tests/validate.cjs：題庫靜態檢核（需 Node.js）。

## 修改劇本

在 data/questions.js 修改 characters、chapters、questions。每個問題包含 id、chapter、type、speaker、tag、title、scene、3個 options、correct（0～2）、explanation、principle。

若更換題目內容，請同步增加版本號，避免舊紀錄混入新題庫。若加入醫療指引、校園請假、資源政策等具體內容，須另行核對現行適用資料與授課場域。
