# 經彩同行 SET｜Google 試算表接收端重新部署與診斷

## 重要：GitHub 更新不會自動改變已部署的 Google Apps Script

網站已改成可見回執頁，並新增接收端健康檢查。要使用這些功能，教師必須將 GitHub 的 google-apps-script/Code.gs **完整覆蓋**到現有 Apps Script 專案，儲存並部署新版本。

## 1. 指定正確試算表（建議一定設定）

在 Apps Script 左側「專案設定」（齒輪）→「指令碼屬性」（Script properties）→ 新增以下屬性：

- 屬性名稱：SET_SPREADSHEET_ID
- 屬性值：17cK-eZDYTMP-Tc4hJmKBM1lGt3X0ef9E--n_vd4AgPg

此值指定教師專用「經彩同行 SET｜學生學習歷程資料庫」。執行 Apps Script 的 Google 帳號**必須具有此試算表的編輯權限**，否則即使網址正確也無法存檔。

若指令碼原本從目標試算表的「擴充功能 → Apps Script」開啟，綁定檔案也可使用，但設定上述屬性更能避免寫到其他活頁簿。

## 2. 貼上新版程式並更新部署

1. 在 Apps Script 編輯器，開啟 Code.gs。
2. 將專案 google-apps-script/Code.gs 的**最新全文**貼入，取代舊程式，按儲存。
3. 選「部署 → 管理部署作業 → 編輯」；選「版本：新增版本」，再按「部署」。
4. 執行身分：我；可存取者：任何人（若學校安全政策不允許公開端點，就不能採此收集模式）。
5. 若要求新增或更新授權，請用具有試算表編輯權限的帳號授權。
6. 確認使用的是已提供的 /exec 正式網頁應用程式網址。

## 3. 先檢查接收端

直接開啟 Google Apps Script /exec 網址（GET）。新版應顯示：

- 「連線診斷通過」：程式已找到目標試算表和三個必要分頁。
- 「接收端尚未準備完成」：照頁面指出的試算表位置／權限／分頁問題處理。

如果仍顯示舊版「經彩同行 SET 學習紀錄接收端已啟用」，表示**部署版本沒有更新**，請回到管理部署作業重新選「新增版本」。

## 4. 測試一次實際寫入

1. 回到 SET 遊戲結算頁；先不用重新答題。
2. 點「送出學習紀錄」；網站會另開 Google 回執頁。
3. 只有看到「學習紀錄已儲存」才算雲端收到；若顯示失敗，按照回執的文字確認權限。
4. 回到試算表，檢查「學習總覽」「逐題作答軌跡」「進階分析」三個分頁。
5. 逐題作答軌跡每次選擇都佔一列；10題全部首次正確會有10列，其中1題重試一次則為11列。

## 可能失敗原因

- 找不到試算表：請設定 SET_SPREADSHEET_ID，且確認用對帳號與目標試算表。
- 找不到分頁：需確認三個工作表名稱與程式完全一致。
- 存取遭拒：Apps Script 執行身分的帳號沒有此檔編輯權限。
- 要求登入學校帳號：學校 Google Workspace 可能限制匿名存取；需查部署權限與學校政策。
- 未收到回執：網站已改成開新分頁，請查看是否被彈出視窗封鎖。

## 資安提醒

- 試算表含未成年學生姓名與作答，應保持非公開，只讓受權限控管的教師存取。
- 公開 Apps Script 收件端無法保證送件身分真實，也無法完全防止惡意送件。
- 如學校不允許匿名公開網頁應用程式，請改採校內受控後端或下載檔案繳交。
