# SET｜平權觀點展示牆：教師專用部署

這是《王子脫魯記 SET》的教師專用審核／匿名投影平台。學生原本的 SET 網站、公開收件 Web App、Google 試算表的三個原始分頁維持不變。

## 已完成準備

教師試算表已新增「展示審核」分頁，A:K 欄依序為：
學習代碼／偏見展示核准／資源展示核准／偏見公開文字／資源公開文字／偏見展示標籤／資源展示標籤／審核更新時間／審核教師／偏見來源指紋／資源來源指紋。

審核資料不修改原始學生文字。新提交內容會在下一次重新讀取時顯示。如果學生重新提交並修改了原始回答，原本的審核將因來源指紋不一致自動失效。

## 安全部署：一定要建立全新的 Apps Script 專案

**不要將教師程式放到原本學生的公開收件 Apps Script 專案。** 學生收件端是公開的，教師端應獨立存取控管。

1. 以學校 Google 帳號進入 https://script.google.com/home/projects/create ，建立名為「SET 平權觀點展示牆」的新專案。
2. 將本資料夾 Code.gs 的完整內容貼進新專案原本的 Code.gs。
3. 左側「檔案」點 ＋ → HTML，檔名設為 Teacher（系統建立 Teacher.html），貼入本資料夾 Teacher.html 的完整內容。
4. 左側「專案設定」→「指令碼屬性」，建立兩個屬性：
   - SET_SPREADSHEET_ID：填入目前教師 SET Google 試算表網址中 /d/ 與 /edit 之間的 ID。
   - SET_WALL_TEACHERS：填入目前登入的教師 Google 帳號完整電子郵件，若未來允許其他教師可用半形逗號分隔（初次建議只填自己）。
5. 儲存，選「部署 → 新增部署作業 → 網頁應用程式」。
6. **執行身分：我；誰可以存取：只有我（Only myself）**。完成授權後部署。
7. 複製新專案的 /exec 網址，在已授權教師帳號登入的瀏覽器中開啟。
8. **勿**將教師端網址放進公開學生網站的 config.js；學生端原有 Apps Script 的 /exec 網址不用變更。

請不要選擇「任何人」存取，勿公開教師試算表。日後如要讓其他教師共用，需要另行檢查試算表共用權限、執行身分、部署權限及學校政策。

## 首次測試

1. 在新教師網站開啟「教師審核」，依班級篩選。
2. 找到有完成進階分析的學生，檢視「月經偏見」與「用品取得障礙」的原始文字。
3. 編輯投影文字，先移除姓名、私密身體經驗與其他可識別資料，再逐則按「核准展示」。
4. 切換「投影展示」，確認只顯示已核准的匿名文字。
5. 點選兩張卡片，按「比較兩則觀點」，檢查並排展示。
6. 回教師審核頁撤銷核准，再重新整理投影，該項應消失。
7. 若學生重新上傳不同的原始答案，舊核准也應自動失效。

## 課堂使用

- 教師審核時含學生姓名與座號，不要將此頁投影給全班。
- 完成審核後再開「投影展示」；展示頁不會顯示班級、座號、姓名或學習代碼。
- 可依班級／月經偏見／資源取得問題篩選，點兩張卡片比較。投影頁每30秒更新一次。
- 內建全螢幕按鈕可能受 Apps Script 內嵌頁限制；可改按瀏覽器 F11。
- 教學實錄如公開發布，即使移除姓名仍應進行校方規範的影像告知與授權，因為獨特的文字內容有時仍可能被認出。

## 故障排除

- 無法確認教師身分：確認 SET_WALL_TEACHERS 與登入帳號一致，且部署存取為「只有我」。
- 找不到進階分析：SET_SPREADSHEET_ID 或教師帳號的試算表權限有誤。
- 找不到展示審核：請確認新分頁位於同一份 SET 教師試算表。
- 欄位名稱或順序不符：展示審核 A1:K1 的標題必須符合本文件上方列出的順序。
- 看不到任何學生：學生尚未完成並上傳進階分析，或資料已超過最近1500筆上限。
- 展示牆空白：所有回答預設不公開，需由教師逐則核准。
- 核准後又消失：學生重交並修改過回覆，為防止顯示未審核新內容，原核准會失效。
- 修改程式後沒有更新：部署 → 管理部署作業 → 編輯 → 新增版本 → 部署。

## 隱私與程式範圍

教師資料不會放在 GitHub Pages。所有後端操作必須通過教師電子郵件白名單檢查；審核只能修改「展示審核」分頁，無法更動學生原始回覆與既有成績。本工具不能替代校方的資訊安全、資料保護與影片公開授權程序。
